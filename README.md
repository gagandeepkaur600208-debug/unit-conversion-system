## Project Description

The Unit Conversion System is a menu-driven Python program that
converts values between commonly used units. The user selects a
conversion category, chooses the conversion direction, and enters a
value.

## Conversion Options

1. Length
   - Kilometers to miles
   - Miles to kilometers
2. Weight
   - Kilograms to grams
   - Grams to kilograms
3. Temperature
   - Celsius to Fahrenheit
   - Fahrenheit to Celsius
4. Time
   - Hours to minutes
   - Minutes to hours

## Python Concepts Used

- Functions
- Conditional statements (if, elif, else)
- User input (input())
- Type conversion (int(), float())
- Exception handling (try and except)
- Formatted strings (f-strings)

## How to Run

1. Make sure Python is installed on your computer.
2. Save the program as one.py.
3. Open a terminal in the folder containing the file.
4. Run:

   python one.py

5. Select a conversion category, choose the conversion direction, and enter the value.

## Input Validation

- The program checks whether the selected category is between 1 and 4.
- It handles invalid numeric input using ValueError.
- It displays an error message if the conversion direction is not 1 or 2.
